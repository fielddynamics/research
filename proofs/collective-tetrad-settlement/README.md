# Collective Tetrad Settlement

A proposed GFD proof connecting complete snapshot registration, four-face closure, the shared vacancy law, and AQUAL. The new algebra is the independent-face obstruction and the collective four-face formulation; the inherited scalar screening and AQUAL energy are explicitly credited. The physical identification with the native vortex Hamiltonian remains open.

- [PROOF.md](PROOF.md): theorem, proofs, counterexamples, source links, and scope.
- [test_collective_settlement.py](test_collective_settlement.py): 90 symbolic and numerical test cases.
- [verification.txt](verification.txt): actual pytest output.

Reproduce: `python -m pytest -q test_collective_settlement.py` (requires NumPy, SciPy, SymPy, pytest).
