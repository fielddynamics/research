# Proofs

*Formal results of Gravity Field Dynamics, each with a plain-language summary and a script that checks every step*

---

Each folder holds one proof: the LaTeX source and PDF, a README that explains in prose what the proof says and why it matters, and a verification script that prints PASS or FAIL for every algebraic step.

Proofs marked **+ Lean** also have a `lean/` folder with a Lean 4 / Mathlib formalisation, checked by GitHub on every change (the badge on each README), and a `LEAN_AUDIT.md` that lists what is proved and what is cited. The formalisations import one another rather than restating definitions, so each chain is checked as a whole:

- forced tetrahedral frame → half-space regions → tetrad scheme → Gram matrix of the tetrad equation → Walsh eigenmodes of the cube
- forced tetrahedral frame → Hadamard cube frame
- constitutive law → AQUAL energy functional
- Walsh eigenmodes of the cube and constitutive law → constitutive law as a tug of war (the cube's share meets the law) → net-field rule (where the law acts) → SST khronon (the preferred frame) → mountain scale (the rule from the action)
- AQUAL energy functional and tetrad scheme → BIMOND two-potential energy (where the two chains meet)
