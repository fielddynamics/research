## The Correspondence

### I Ching Structure
- 8 trigrams (三卦)
- Each trigram = 3 binary lines (yin/yang)
- 3 bits → 8 possible states (0-7)

### Merkaba Structure
- 8 vertices
- Each vertex = 3 binary coordinates
- 3 bits → 8 possible positions (0-7)

### Mathematical Isomorphism
Both systems are instances of the same mathematical structure: **Z₂³** (the group of 3-bit binary strings).
