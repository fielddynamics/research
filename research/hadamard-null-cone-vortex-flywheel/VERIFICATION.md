# Reproduce the mathematical research

This edition reorganizes the existing seven stages; it does not introduce a new physical theorem. All seven original Python suites and their recorded output are retained. The new synthesis figure is generated by `generate_synthesis_figure.py`.

## Python setup

Use Python 3 with NumPy, SciPy, SymPy and Matplotlib. From this folder:

```sh
python -m pip install numpy scipy sympy matplotlib
python verify_sustained_flywheel.py
```

The sustained verifier runs the foundational and current-closure assertions on import (984) and performs 809 new assertions. To reproduce every stage separately:

Figure generators are retained; run the matching generator after its verifier. For the new geometry figure run `python generate_synthesis_figure.py`.
